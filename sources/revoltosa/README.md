# La Revoltosa

Оригинал: https://larevoltosa.es. Адрес копии: `/revoltosa/`.

`public/` содержит 23 страницы: главную с объёмной бутылкой и анимациями
прокрутки, каталог с двумя видами отображения, девять напитков, историю,
новости, прессу и служебные страницы. Сохранены пузырьки и волнистое меню.

Модели, текстуры и шрифты находятся здесь. Идентичные Draco-декодеры вынесены
в `../../shared/public/string-tune/libs/draco/`; сборка сохраняет их прежний URL.
Обычные фотографии, видео и документы используют публичные адреса оригинала,
чтобы весь проект помещался в лимит хостинга.
Аналитика отключена, форма демонстрационная.
Скриншот опубликованной версии находится в `previews/`.

## Повторный перенос

```sh
python3 websites/revoltosa/scripts/download.py
python3 websites/revoltosa/scripts/install.py
```

## Сборка и просмотр

Команды выполняются из корня `website-collection`:

```sh
python3 tools/build.py
python3 tools/verify_sites.py
python3 tools/preview.py
```

Редактируйте `public/` в этой папке; `dist/` создаётся автоматически.
Общее меню и общие библиотеки находятся в `../../shared/`.
После повторного импорта запустите `python3 shared/scripts/install_menu.py`.
