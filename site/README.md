# Actimed — сайт онлайн-аптеки

Сайт на обычных HTML, CSS и JavaScript, без сборки. Блоки сделаны по мотивам
сайтов из `../sources/`. Сами исходники не изменялись, чужой код, фото,
шрифты и модели в сайт не скопированы.

| Блок | Идея взята из | Файлы |
|---|---|---|
| Главный экран: упаковки и кольцо с текстом двигаются при прокрутке | Agrumea | `index.html`, `js/main.js` |
| «Мы бережём ваше здоровье» и три карточки | Mantis | `index.html` |
| 3D-лента категорий над сеткой, едет от прокрутки и перетаскивания | Jesper | `js/ribbon.js` (three.js) |
| Каталог: фильтры, поиск, вид «Плитка / Список», корзина | Revoltosa | `js/main.js`, `js/data.js` |
| Футер: поднимающийся купол, упругая струна, восьмиугольник | String-tune | `js/footer.js` |

## Правила

- **Нет анимаций при наведении.** Ни `transition`, ни движения на `:hover`.
  При наведении меняется только цвет или подчёркивание, мгновенно.
- Движение есть только от прокрутки, перетаскивания ленты и плавное покачивание упаковок на первом экране.
- При системной настройке «Уменьшить движение» анимации отключаются.

## Цвета

Задаются в начале `css/style.css` (`:root`):

| Переменная | Цвет | Где |
|---|---|---|
| `--primary` | `#0E6E6E` сине-зелёный | кнопки, первый экран |
| `--accent` | `#2FA36B` зелёный | логотип, акценты |
| `--mint` | `#CDEDE3` мятный | светлые кнопки на тёмном фоне |
| `--deep` | `#0B2E33` тёмно-бирюзовый | лента категорий, футер |
| `--bg` | `#F4F8F7` | фон страницы |

## Как поменять товары

Товары и категории лежат в `js/data.js`. Цены указаны в сумах.

## Запуск

```sh
cd site
python3 -m http.server 8000
```

Откройте http://localhost:8000. Если открыть файл двойным щелчком, 3D-лента
не загрузится: браузер не разрешает модули с `file://`.

`vendor/three.module.min.js` — библиотека three.js r160 (лицензия MIT, `vendor/three.LICENSE`).
