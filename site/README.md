# Actimed — сайт онлайн-аптеки

Статичный сайт на HTML, CSS и JavaScript, без сборки. Блоки сделаны по мотивам
сайтов из `../sources/`; сами исходники не изменялись, чужой код и картинки в
сайт не копировались — всё написано и нарисовано заново.

## Страницы

| Страница | По мотивам | Файлы |
|---|---|---|
| **Главная** — только лента товаров во весь экран | Jesper | `index.html`, `js/ribbon.js` (three.js) |
| **Страница товара** — `product.html?id=<id>` | Agrumea | `product.html`, `js/product.js` |
| **Меню** во весь экран и шапка — на всех страницах | Agrumea | `js/menu.js` |
| **Футер** внизу страницы товара | String-tune | `js/footer.js` (StringTune) |

### Главная: лента

- Карточка товара разделена белой полосой: слева 40% — описание на матовом
  полупрозрачном «стекле», справа 60% — картинка.
- Лента бесконечная: колесо и тачпад, свайп, перетаскивание, стрелки. После
  остановки ближайшая карточка встаёт на место. Клик открывает страницу товара.
- Изгиб идёт только в глубину (перспектива), без перекоса; при быстрой
  прокрутке края ленты слегка приподнимаются и закручиваются.
- `index.html?group=meds|vitamins|care` — лента одной группы (пункты меню).

### Страница товара

Огромное название, по бокам категория и форма выпуска; упаковка при прокрутке
взлетает с наклоном. Ниже: описание с ромбами, три колонки (как принимать,
фасовка, срок годности), цена и «В корзину», лента картинок, «Другие товары»,
футер с поднимающейся тёмной горой.

Корзина пока только считает товары (хранится в браузере посетителя).

## Правила

- **Нет анимаций при наведении**: ни `transition`, ни движения на `:hover`.
  Движение — от прокрутки, перетаскивания и по клику (открытие меню).
- «Уменьшить движение» в системе отключает плавную прокрутку, гору в футере,
  взлёт упаковки и реакцию ленты на скорость.

## Логотип

`img/logo-mark.svg` — знак, перерисованный по картинке логотипа (наклонный
штрих «А» и лист); надпись ACTIMED набрана шрифтом Jost. Знак используется как
маска, поэтому перекрашивается под тему. **Когда будет исходник логотипа (SVG),
замените этот файл** — шапка, футер и иконка вкладки подхватят его сами;
картинки товаров перерисуйте командой ниже.

## Товары и картинки

- Товары, группы и тексты — `js/data.js` (цены в сумах). Медицинские тексты
  общие и требуют проверки фармацевтом перед запуском.
- Картинки: `img/cards/` (карточки ленты), `img/products/` (упаковки),
  `img/footer/` — рисуются из шаблона `tools/scene.html`:
  ```sh
  cd site
  npm i -D playwright            # один раз
  node tools/render-images.mjs   # все картинки
  node tools/render-images.mjs ibuprofen   # один товар
  ```

## Запуск

```sh
cd site
python3 -m http.server 8000
```

Откройте http://localhost:8000. Двойной щелчок по `index.html` не подойдёт:
браузер не загружает модули с `file://`. Шрифты грузятся с Google Fonts.
