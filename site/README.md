# Actimed — сайт онлайн-аптеки

Статичный сайт на HTML, CSS и JavaScript, без сборки. Блоки сделаны по мотивам
сайтов из `../sources/`. Сами исходники не изменялись; чужой код, фото, шрифты
и модели в сайт не копировались — всё написано и нарисовано заново.

| Блок | По мотивам | Файлы |
|---|---|---|
| Главный экран: упаковки и кольцо с текстом двигаются при прокрутке | Agrumea | `index.html`, `js/main.js` |
| «Мы бережём ваше здоровье» и три карточки | Mantis | `index.html` |
| 3D-лента категорий над сеткой | Jesper | `js/ribbon.js` (three.js) |
| Каталог: фильтры, поиск, «Плитка / Список», корзина | Revoltosa | `js/main.js`, `js/data.js` |
| Футер: тёмная гора поднимается снизу, струна, зеркальная надпись, восьмиугольник с блистерами | String-tune | `js/footer.js` (StringTune) |

## Как устроены анимации

- **Плавная прокрутка** на компьютере — библиотека StringTune (та же, что на
  string-tune.fiddle.digital). На телефоне прокрутка обычная.
- **Лента.** Карточки едут сквозь неподвижную «волну» глубины: изгиб идёт только
  по оси z, поэтому контур карточки меняется за счёт перспективы, без перекоса.
  Гребень волны левее центра. При быстрой прокрутке края ленты слегка
  приподнимаются и закручиваются, в покое всё ровно. Управление — прокрутка
  страницы (секция закреплена) и перетаскивание мышью или пальцем.
- **Футер.** Слой во весь экран закреплён у нижнего края; по мере прокрутки на
  нём растёт тёмная гора и к концу раскрывается в прямоугольник, закрывая
  предыдущий блок. Струна между заголовками дёргается, когда пересекает
  середину экрана. Блистеры поверх восьмиугольника едут с параллаксом.

## Правила

- **Нет анимаций при наведении.** Ни `transition`, ни движения на `:hover`;
  при наведении мгновенно меняется только цвет или подчёркивание, над лентой —
  курсор.
- При системной настройке «Уменьшить движение» плавная прокрутка, гора и
  реакция ленты на скорость отключаются.

## Цвета

В начале `css/style.css` (`:root`): `--primary` #0E6E6E, `--accent` #2FA36B,
`--mint` #CDEDE3, `--deep` #0B2E33 (лента и футер), `--bg` #F4F8F7.

## Товары и картинки

- Товары и категории — `js/data.js` (цены в сумах).
- Картинки карточек ленты (`img/categories/`), восьмиугольника и блистеров
  (`img/footer/`) рисуются из шаблона `tools/scene.html`:
  ```sh
  cd site
  npm i -D playwright      # один раз
  node tools/render-images.mjs
  ```

## Запуск

```sh
cd site
python3 -m http.server 8000
```

Откройте http://localhost:8000. Двойной щелчок по `index.html` не подойдёт:
браузер не загружает модули с `file://`. Шрифты грузятся с Google Fonts.
